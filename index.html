同一套的工具

網站論文指南研究方法、論文寫作和口試，每一站該怎麼做的說明。 Claude Code 外掛thesis-toolkit幫你收斂題目、稽核研究問題、檢查學術寫法的 SKILL。 Obsidian 範本論文筆記庫範本文獻筆記、構念卡和假說推導放在同一個筆記庫，寫第二、三章時直接取材。 簡報工具md-to-slides用 Markdown 寫簡報，挑場合和主題就有一份範例可以改。 Claude Code 設定Claude Code 工作流 template開場接上次進度，產出交給另一個 agent 驗收，論文跨很多 session 也不會斷。
